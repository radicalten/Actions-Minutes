Why these changes / 03

Failure points

01

NDS blocks overrun the scheduler

A 48-instruction JIT block is accounted for only after it finishes. ARM9, ARM7, DMA, timers, and IRQ events can occur mid-block. The safe path preserves the interpreter's event ordering rather than claiming that a cycle estimate makes the JIT cycle-exact.

Safe fallback
02

Thumb BL can cross a page boundary

A paired halfword can be compiled from the next page, while page coverage only records the first. The patch requires both halves in one page; otherwise the interpreter handles the pair.

Invalidation
03

ADC / SBC / NEG flags alias their operands

When Thumb source and destination registers are the same, calculating V after writing the result reads the new source value. Snapshot the source before the arithmetic.

NZCV
04

Empty Thumb register lists are special

The handwritten LDM/STM helper only advances the base register. Let the interpreter handle empty lists, which can also access memory and have architecture-specific behavior.

Fallback

Next: compare per-instruction registers, CPSR, PC, memory writes and cycle counts against the interpreter; then re-enable NDS JIT with an event-budgeted dispatcher. Also audit resetCycles() against g_cpuTime, ARM9 CP15 mapping, IRQ entry, and banked-register mode changes. This patcher deliberately does not claim to solve those unverified paths.
