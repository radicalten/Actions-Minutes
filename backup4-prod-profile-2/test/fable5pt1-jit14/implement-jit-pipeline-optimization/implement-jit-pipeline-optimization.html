Build / bring-up checklist

  1. No interpreter changes are required. The file only uses what the old one used: getRegisters(), getCpsrRef(), setPC(), getActualPC(), isThumb(), isReady(), jitRunOpcode(), bios, halted.
  2. Wii build must define HW_RVL (libogc does) so SYS_AllocArena2MemLo is available; otherwise it silently falls back to a 2 MB MEM1 buffer.
  3. Expected boot log: [JIT] ready buf=0x9xxxxxxx (16384KB MEM2) pages=256 BLK_ARMS=48. If it says MEM1, your Noods_MEM2 arena already claimed Arena2 — carve the 18 MB from that allocator instead.
  4. executeBlock_asm is now called with the per-CPU entry stub, never with block code. The entry stub reads the block pointer from g_nextBlock, so the asm trampoline needs no changes.
  5. First normal exit per CPU/mode calls setPC() once to learn the r15 offset; every exit after that just stores pc + off. If a fork's setPC has side effects beyond r15 + pipeline, add them to JitHelp_commit.
  6. Timing knob: armCycles()/thumbCycles() (1 per insn, +1 memory, +1 per LDM/STM register). If a title becomes unstable, charge more for loads.
